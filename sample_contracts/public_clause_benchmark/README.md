# 公开披露合同条款级评测集

本目录包含 25 份中国政府采购网公开合同公告中裁出的 70 条短条款，覆盖软件开发与运维、AI 技术服务、驻场服务、设备采购、食材配送、维修工程、工程造价和房屋鉴定等类型。每条正文控制在 100-900 字，优先覆盖验收、付款、违约，缺失时使用保密、质保、不可抗力或争议条款替代。长违约责任条款可按互不重叠的子条款切成重点核查点。

## 数据边界

- 来源是官方公开合同公告，不是企业授权的私有合同。
- 已对正文做二次脱敏：主体、联系人、联系方式、地址、账户/证照、项目编号、项目专名与 OCR 水印机构名均被删除或泛化。
- OCR 可能有错字、漏字或断行，因此每条都标记为 `ocr_review_required`；生成器会丢弃不足 100 字的无效片段，但这不能替代逐条人工复核。不得把本目录直接当作法律事实或训练语料发布。
- `manifest.json` 保留来源页 URL 供核验；若要面向最终用户公开数据集，应将该文件移出发布包，避免通过来源页回溯主体。

## 用于评测的方式

每个文本文件代表一个“真实文本风格”的输入单元。后续人工标注应至少增加：

1. `clause_span`：条款定位；
2. `risk_type`：例如付款条件、验收标准、违约责任；
3. `risk_label`：有风险 / 无明显风险 / 需人工判断；
4. `gold_articles`：支持结论的法律名与条号；
5. `reviewer` 与 `review_date`：保留人工复核痕迹。

这是一套外部条款级验证集，应与项目现有的 AI 合成埋点合同集分开报告结果：合成集用于回归与风险模式覆盖，公开条款集用于小规模外部验证；两者均不能替代带完整上下文、经双人律师复核的真实合同评测集。

## 当前标注状态与测评

- `manifest.json`：25 份合同裁出的 70 条有效短条款；15 份扩展合同均来自中国政府采购网官方合同公告附件。
- `annotations.json`：95 条记录，包括 30 个已计分正样本点、13 个已计分负样本、10 个排除项，以及 42 条 `pending_review` 扩展条款。扩展条款在独立人工复核前不参与指标计算。
- `eval_report.json`：30 条正样本在 2026-09-05 的单次完整运行结果：Top-5 金标法条命中 30/30（MRR 0.375），完整 Agent 金标法条命中 30/30；无效引用为 0，无本轮依据引用为 1。后者来自样本 `04_middleware_support_03_liability_p3` 对未检索《民法典》第583条的文字提及，已被证据白名单校验器标注警告。
- Agent 评测现要求首行输出固定风险判定，并自动统计 TP、FP、FN、TN、Precision、Recall、F1 和 Accuracy；旧报告尚未按新协议重跑，因此 README 不提前公布这些指标。
- 8 条父级长条款因已拆为子条款、2 条 OCR 噪声不参与打分。

## 扩展流程

1. `import_public_contracts.py` 支持按合同 ID 增量导入，也可用 `--from-raw` 处理已取得的官方扫描附件；OCR 只在本地执行。
2. `build_public_clause_benchmark.py --ids ...` 增量裁切条款并合并 manifest，兼容中文、阿拉伯数字和章节式标题。
3. `annotate_public_clause_benchmark.py` 同步标注文件，新扩展条款默认进入 `pending_review`，不会自动伪装成金标。
4. 独立复核人员补齐 `risk_label`、`gold_articles`、`reviewer` 与 `review_date` 后，才允许进入计分 split。

运行：`python -X utf8 -m backend.scripts.eval_public_clauses --agent`。该命令会调用模型并覆盖 `eval_report.json`。
